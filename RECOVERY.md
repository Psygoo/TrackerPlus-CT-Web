# Recovery and returning to stock

Keep an untouched official Tracker+ 1.2.0 PTF and a separate SD/Workspace/project
backup before installing. Recovery is not guaranteed by this project.

If the device still opens Config, follow the official normal update process
using official firmware. If it does not boot normally, consult
[section 13.3 of the official Tracker+ manual](https://polyend-website.fra1.digitaloceanspaces.com/wp-content/uploads/2024/05/08111709/Polyend-TrackerPlus-Manual-1v1v0c.pdf#page=318)
and follow Polyend's recovery instructions for the pinhole recovery button near
USB while powered on. The manual describes recovery searching the Firmware
folder and selecting a firmware file. Because that selection can be arbitrary,
prepare a recovery SD card with **only the verified official stock PTF eligible
in Firmware**; do not leave multiple modified images there. This is a project
precaution, not an additional official guarantee.

Use firmware for the exact Tracker+ model, reliable power and the official
procedure. If recovery fails, use [Polyend support](https://polyend.com/support/).
A firmware rollback does not restore or migrate project data: use backed-up
copies appropriate to that firmware. Do not overwrite the only copy of a project.
